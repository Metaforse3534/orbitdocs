Every request to the Orbit AI API must include a valid API key. Authentication uses the standard HTTP `Authorization` header with a `Bearer` token scheme. There are no cookies, sessions, or OAuth flows — just your key on every call.

## Getting an API Key

Create and manage your API keys from the [Developer Portal](https://app.orbitdev.org/developer). After signing in:

<Steps>
  <Step title="Open the Developer Portal">
    Navigate to [app.orbitdev.org/developer](https://app.orbitdev.org/developer) and sign in with your Orbit account.
  </Step>
  <Step title="Generate a new key">
    Click **Create API Key**, give it a descriptive name (for example, `production-backend` or `local-dev`), and confirm.
  </Step>
  <Step title="Copy your key immediately">
    The full key value is shown only once. Copy it to a secure location such as a password manager or secrets vault before closing the dialog.
  </Step>
</Steps>

All API keys begin with the prefix `orb_`.

## Authorization Header Format

Pass your key in the `Authorization` header on every request:

```
Authorization: Bearer orb_your_api_key
```

### Example Request

```bash
curl https://api.orbitdev.org/v1/usage \
  -H 'Authorization: Bearer orb_your_api_key'
```

## Using Environment Variables (Recommended)

Hard-coding API keys in source code is a security risk. Store the key in an environment variable and reference it in your requests and application code instead.

```bash
export ORBIT_API_KEY=orb_your_api_key

curl https://api.orbitdev.org/v1/usage \
  -H "Authorization: Bearer $ORBIT_API_KEY"
```

In your application, read the variable from the environment at runtime:

<Tabs>
  <Tab title="Node.js">
    ```javascript
    const apiKey = process.env.ORBIT_API_KEY;

    const response = await fetch('https://api.orbitdev.org/v1/usage', {
      headers: {
        'Authorization': `Bearer ${apiKey}`,
      },
    });
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import os
    import requests

    api_key = os.environ["ORBIT_API_KEY"]

    response = requests.get(
        "https://api.orbitdev.org/v1/usage",
        headers={"Authorization": f"Bearer {api_key}"},
    )
    ```
  </Tab>
</Tabs>

## Authentication Error Responses

| Status Code | Meaning |
|---|---|
| `401 Unauthorized` | The `Authorization` header is missing, malformed, or contains an invalid key. Check that the `Bearer ` prefix is present and the key value is correct. |
| `403 Forbidden` | The key is valid but does not have permission to access this resource. This can occur if the key was created under a plan that does not include the requested endpoint. |

A `401` response body looks like:

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid or missing API key."
  }
}
```

## Key Rotation

Rotate your API key whenever you suspect it has been compromised or when a team member with access departs. In the [Developer Portal](https://app.orbitdev.org/developer), delete the old key and generate a replacement. Update your secrets vault and all deployment environments before deleting the old key to avoid downtime.

<Warning>
  Never embed your API key in client-side code, mobile app binaries, or public repositories. Anyone who obtains your key can make requests billed to your account. If a key is exposed, revoke it immediately from the Developer Portal.
</Warning>

<Info>
  For key management options such as listing, renaming, and revoking keys, see the [API Keys](/account/api-keys) page in your account settings.
</Info>
