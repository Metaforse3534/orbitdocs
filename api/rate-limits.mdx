The Orbit AI API enforces rate limits to ensure fair usage and stable performance for all users. Limits apply per API key and are measured in two dimensions: requests per minute (burst) and requests per month (quota). Exceeding either limit returns a `429 Too Many Requests` response.

To unlock higher limits, purchase Paid tier API access from the [Developer Portal](https://app.orbitdev.org/developer). The upgrade is a one-time payment of **€10** — there is no recurring subscription for the tier itself. Your increased limits take effect immediately after payment.

## Rate Limit Headers

When a request is rate-limited, the API returns a `429 Too Many Requests` status with a JSON body:

```json
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "You have exceeded your requests-per-minute limit. Please retry after 1 second."
  }
}
```

## Handling 429 Responses

The recommended strategy for handling rate limits is **exponential backoff with jitter** — wait progressively longer between retries, with a small random component to prevent synchronized retry storms from multiple clients.

```javascript
async function callWithRetry(fn, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    const response = await fn();
    if (response.status !== 429) return response;
    const delay = Math.pow(2, attempt) * 1000 + Math.random() * 500;
    await new Promise(resolve => setTimeout(resolve, delay));
  }
  throw new Error('Max retries exceeded');
}
```

The delay schedule for `maxRetries = 3` looks like:

| Attempt | Base Delay | Jitter (random) | Approximate Wait |
|---|---|---|---|
| 1st retry | 1,000 ms | 0–500 ms | ~1.0–1.5 s |
| 2nd retry | 2,000 ms | 0–500 ms | ~2.0–2.5 s |
| 3rd retry | 4,000 ms | 0–500 ms | ~4.0–4.5 s |

Wrap any API call that may encounter a `429` response with this pattern:

```javascript
const response = await callWithRetry(() =>
  fetch('https://api.orbitdev.org/v1/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.ORBIT_API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      messages: [{ role: 'user', content: 'Hello!' }],
      mode: 'auto',
    }),
  })
);
```

<Tip>
  Before starting any batch operation that will send many requests, call `GET /v1/usage` to check how many requests you have remaining in your current billing period. If you are close to your monthly limit, consider purchasing a credit pack or scheduling the batch job after your quota resets.
</Tip>

## Quota Reset

Monthly quotas reset on the first day of each calendar month at 00:00 UTC. The exact reset timestamp for your account is returned in the `requests.resetsAt` field of the [`GET /v1/usage`](/api/usage) response.
