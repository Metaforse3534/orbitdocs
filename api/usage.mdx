The usage endpoint returns a snapshot of your API key's current billing state: which tier you are on, how many requests you have made this month, your monthly limit, and your per-minute rate limit. Call this endpoint any time you need to understand your remaining capacity before running workloads.

## Endpoint

```
GET https://api.orbitdev.org/v1/usage
```

This is a read-only endpoint — no request body is required. Authenticate with your API key in the `Authorization` header as with all other endpoints.

## Example Request

```bash
curl https://api.orbitdev.org/v1/usage \
  -H 'Authorization: Bearer orb_your_api_key'
```

## Example Response

```json
{
  "tier": "paid",
  "requests": {
    "used": 347,
    "limit": 10000,
    "resetsAt": "2024-02-01T00:00:00Z"
  },
  "rateLimit": {
    "requestsPerMinute": 30
  }
}
```

## Response Fields

<ResponseField name="tier" type="string">
  The current API access tier for this key. Either `"free"` or `"paid"`.

  | Value | Monthly Limit | Rate Limit |
  |---|---|---|
  | `"free"` | 100 requests | 5 req/min |
  | `"paid"` | 10,000 requests | 30 req/min |
</ResponseField>

<ResponseField name="requests" type="object">
  Aggregate request counts for the current billing period.

  <ResponseField name="requests.used" type="integer">
    Total number of API requests made since the start of the current billing period.
  </ResponseField>

  <ResponseField name="requests.limit" type="integer">
    Maximum number of requests allowed in a single billing period under your current tier. `100` on Free, `10000` on Paid.
  </ResponseField>

  <ResponseField name="requests.resetsAt" type="string">
    ISO 8601 UTC timestamp of when the monthly quota resets. Quotas reset on the first day of each calendar month at 00:00 UTC.
  </ResponseField>
</ResponseField>

<ResponseField name="rateLimit" type="object">
  Per-minute burst limit information.

  <ResponseField name="rateLimit.requestsPerMinute" type="integer">
    Maximum number of requests you can make within any 60-second window. `5` on Free, `30` on Paid.
  </ResponseField>
</ResponseField>

## Calculating Remaining Quota

To determine how many requests you have left in the current billing period, subtract `requests.used` from `requests.limit`:

```javascript
const response = await fetch('https://api.orbitdev.org/v1/usage', {
  headers: {
    'Authorization': `Bearer ${process.env.ORBIT_API_KEY}`,
  },
});

const usage = await response.json();
const remaining = usage.requests.limit - usage.requests.used;

console.log(`Tier: ${usage.tier}`);
console.log(`Requests used: ${usage.requests.used} / ${usage.requests.limit}`);
console.log(`Remaining: ${remaining}`);
console.log(`Resets at: ${usage.requests.resetsAt}`);
```

<Tip>
  Call this endpoint at the start of any batch job that will send multiple API requests. If the remaining quota is lower than the number of requests you need, purchase a [credit pack](/api/rate-limits#credit-packs) or schedule the batch after your quota resets rather than letting it fail mid-run.
</Tip>

## Upgrading Your Tier

If you are on the Free tier and need higher limits, upgrade to the Paid tier from the [Developer Portal](https://app.orbitdev.org/developer) for a one-time fee of **€10**. Your `tier` field in the usage response will update to `"paid"` immediately after the upgrade is applied.

<Info>
  Usage data is updated in near real-time. There may be a delay of a few seconds between making a request and seeing the updated `requests.used` count reflected in the usage response.
</Info>
