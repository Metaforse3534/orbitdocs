Files & Research gives you a direct way to bring your own documents into any Orbit AI session. Instead of copying and pasting content manually, you upload a file and it becomes part of the active context — ready for chat queries, agent tasks, and structured research workflows. Whether you need a quick summary of a lengthy report or a deep cross-document analysis, Files & Research keeps your source material close to the intelligence acting on it.

## Supported File Types

Orbit AI accepts a range of common document and text formats. Upload plain text files, formatted documents, and structured data files directly from your device. If you are unsure whether a specific format is supported, check the attachment dialog in the workspace — only compatible file types are selectable.

## How to Attach a File

<Steps>
  <Step title="Open a chat or agent run">
    Navigate to [app.orbitdev.org](https://app.orbitdev.org) and open an existing chat session or start a new agent run in your workspace.
  </Step>
  <Step title="Click the attachment icon">
    Locate the attachment icon in the input area at the bottom of the chat or agent panel and click it to open the file picker.
  </Step>
  <Step title="Select your file">
    Browse to the file on your device and select it. The file uploads and its contents are parsed into the session.
  </Step>
  <Step title="Start your request">
    The file content is now part of the session context. Type your question or task prompt — Orbit AI will reason over the document as part of its response.
  </Step>
</Steps>

## What You Can Do With Attached Files

Once a file is part of your session context, you can direct Orbit AI to work with it in a wide variety of ways:

<CardGroup cols={2}>
  <Card title="Summarize Long Documents" icon="file-lines">
    Ask Orbit to condense lengthy reports, contracts, or articles into clear, structured summaries — preserving the key points without the noise.
  </Card>
  <Card title="Extract Specific Facts or Data" icon="magnifying-glass">
    Pull out exact figures, dates, names, or statements from a document without reading it line by line yourself.
  </Card>
  <Card title="Compare Multiple Documents" icon="code-compare">
    Attach two or more files to the same session and ask Orbit to identify differences, contradictions, or overlapping themes across them.
  </Card>
  <Card title="Use as Agent Research Material" icon="robot">
    Feed a file directly to an agent run so the agent has authoritative source material to reference when completing its assigned task.
  </Card>
</CardGroup>

## The Researcher Agent and File-Heavy Tasks

The **Researcher** agent type is purpose-built for tasks that depend on dense source material. While any agent or chat session can accept attached files, the Researcher agent is optimized to read deeply, cross-reference content, and produce well-cited, synthesized outputs — making it the right choice when your task is primarily about understanding or extracting value from documents.

<Tip>
  For the most thorough document analysis, attach your files and run a **Researcher** agent task rather than a standard chat session. The Researcher agent is specifically tuned to ingest, cross-reference, and synthesize document content, so you get deeper extraction and more structured outputs from the same source material.
</Tip>

## File Privacy and Data Handling

Your documents are processed entirely within Orbit's secure, GDPR-compliant infrastructure. File content is used solely to fulfill the session request and is handled under Orbit Labs' published data processing terms.

<Note>
  Files you upload are processed under Orbit's GDPR-compliant data policy. Orbit Labs is headquartered in the Netherlands and operates under EU data protection standards. Review the full policy at [orbitdev.org/Routes/privacy.html](https://www.orbitdev.org/Routes/privacy.html).
</Note>
